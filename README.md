# Programação Orientada a Objetos (POO)

Este repositório é dedicado ao armazenamento de atividades, exercícios e projetos desenvolvidos ao longo da disciplina de **Programação Orientada a Objetos (POO)**.

---

## 📌 Conteúdos e Conceitos Abordados

Neste repositório, você encontrará implementações focadas nos pilares e conceitos fundamentais da Orientação a Objetos:

- [x] **Abstração** (Classes e Objetos)
- [x] **Encapsulamento** (Getters, Setters e Modificadores de Acesso)
- [x] **Herança** (Reaproveitamento de código)
- [x] **Polimorfismo** (Sobrescrita e Sobrecarga de métodos)
- [x] **Classes Abstratas e Interfaces**
- [x] **Tratamento de Exceções**
